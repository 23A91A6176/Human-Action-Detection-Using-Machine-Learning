# Human Action Detection using Machine Learning

This project focuses on Human Action Detection using Machine Learning, implemented in a Jupyter Notebook. It analyzes human action data, applies preprocessing and feature extraction, and trains a classification model to recognize different human actions. The notebook includes model training, evaluation, and performance analysis.

## Features
- Data preprocessing and cleaning
- Feature extraction / normalization
- Machine Learning model training
- Model evaluation (accuracy and metrics)
- Prediction on sample inputs

## Tech Stack
- Python
- Jupyter Notebook
- NumPy, Pandas
- Scikit-learn
- Matplotlib / Seaborn

## Output
The notebook provides action classification results along with evaluation metrics and visualizations.
